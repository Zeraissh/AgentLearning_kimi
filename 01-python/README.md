# 阶段 1：Python 基础（第 1-3 月）

配套教材：《Python 编程：从入门到实践》（或廖雪峰 Python 教程，章节对应见下）。

## 学习方法

- 边看边敲，**不复制粘贴**——肌肉记忆是敲出来的
- 每章代码放对应目录，做完 `git add + commit + push`
- 报错先自己读 5 分钟（从最后一行往前读），解决不了再问我——读报错是核心能力

## 第 1-2 周：变量、字符串、数字（书第 1-2 章）

- [ ] 要点：变量命名、字符串方法（`upper/lower/strip/split/join`）、f-string、整数/浮点数、`type()`
- [ ] 练习（存到 `ch01-02/`）：
  1. `hello.py`：用 f-string 打印自我介绍
  2. `name_cases.py`：把一个名字变量分别转成全大写、全小写、首字母大写
  3. `calc.py`：计算并打印——今年你的年龄、离 100 岁还有多少年

## 第 3-4 周：列表与循环（书第 3-4 章）

- [ ] 要点：列表增删改查、切片、`for` 循环、`range()`、列表推导式、元组
- [ ] 练习（存到 `ch03-04/`）：
  1. `guests.py`：维护一个客人名单——添加、删除、按字母排序打印
  2. `squares.py`：用循环和列表推导式各生成一次 1-10 的平方列表
  3. `slices.py`：对一个列表分别取前 3 个、后 3 个、中间一段、反转整个列表

## 第 5-6 周：if、字典、用户输入、while（书第 5-7 章）

- [ ] 要点：条件判断、字典的增删改查与遍历、`input()`、`while` 与 `break/continue`
- [ ] 练习（存到 `ch05-07/`）：
  1. `fav_numbers.py`：字典存 5 个人的幸运数字并逐个打印
  2. `poll.py`：用 while 循环做一个小调查，把结果存进字典，最后汇总打印

## 第 7-9 周：函数、类（书第 8-9 章）★ 重点

- [ ] 要点：参数（位置/关键字/默认/`*args/**kwargs`）、返回值、模块导入；类的属性/方法/继承
- [ ] 这两章是 Agent 开发的地基，不赶进度，习题全做

## 第 10-12 周：文件、异常、测试 + 验收项目（书第 10-11 章）

- [ ] 要点：读写文件、JSON 存取、`try/except`、`pytest` 基本用法
- [ ] **验收项目：命令行文件整理工具**（`file_organizer/`）：
  - 按扩展名把指定目录的文件分类移动到子目录
  - 有 `--dry-run` 模式（只打印不移动）、有 README、有至少 3 个 pytest 测试
  - 达标才算完成阶段 1

## 卡住时的求助格式

贴给我：① 完整报错信息 ② 相关代码 ③ 你试过的办法。这样我能最快定位，你也练了提问能力。

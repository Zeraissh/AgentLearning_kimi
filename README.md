# Learning — 零基础转码 → Agent 应用工程师

目标：12~18 个月达到一线大模型公司（目标：月之暗面）Agent 应用工程岗的能力标准。

## 阶段地图

| 目录 | 阶段 | 时间 | 验收 |
|---|---|---|---|
| `00-setup/` | 环境与工具 | 第 1-2 周 | 代码能推上 GitHub，会用 venv/pip |
| `01-python/` | Python 与编程基础 | 第 1-3 月 | 命令行工具（有 README + 测试） |
| `02-backend/` | 后端与工程能力 | 第 4-5 月 | 部署上线的 REST API 服务 |
| `03-llm-app/` | LLM 应用开发核心 | 第 6-8 月 | 作品集项目 1：多工具 Agent |
| `04-projects/` | 深入与差异化 | 第 9-12 月 | 作品集项目 2 + 开源 PR |
| `05-job-prep/` | 求职冲刺 | 第 13-15 月 | 简历、刷题、投递 |

## 原则

- 70% 动手写代码，30% 看教程
- 每周产出 commit + 学习笔记（见 `LOG.md`）
- 验收不达标不进入下一阶段
- 每 3 个月核对一次目标公司在招 JD，校准方向
